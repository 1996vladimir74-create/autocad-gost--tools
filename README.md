# AutoCAD GOST Tools v1.0


## Назначение

Автоматическое создание листов КД в AutoCAD.


## Возможности

- создание DWG
- форматы А0-А4
- рамка ЕСКД
- основная надпись
- слои


## Требования

- Windows
- AutoCAD
- .NET COM доступ


## Сборка

Запустить:

build_windows.bat


Результат:

dist/AutoCAD_GOST_Tools.exe
